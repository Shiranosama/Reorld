## Reorld
一个极简的[hister](https://github.com/asciimoo/hister) API封装，适用于PowerToys CommandPalette

### 特性
- 自定义服务器域名
- /search API支持
  + 可配置项：
    - limit
    - sort
- /api/preview API支持
  + 可配置项：
    - 是否启用预览（关闭时使用Description替代）
    - 预览长度上限
